# Volatility Analysis Tool

A browser-based dashboard for analyzing live Volatility Index market data.

## Features

- Live market-data dashboard
- Volatility Index selector
- API-token connection interface
- Last-digit distribution
- Even/Odd statistics
- Over/Under statistics
- Repeating-pattern analysis
- Recent tick history
- Responsive mobile interface
- Automatic statistical calculations
